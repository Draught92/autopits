Datos que se solicitan

En la página pública se recopilan el nombre y datos básicos del vehículo, servicio solicitado, fecha u horario de preferencia y descripción de la necesidad. No se solicita el número telefónico en el formulario. El taller puede registrar internamente el número de contacto identificado en WhatsApp, placas, diagnóstico, autorización, historial y otros datos necesarios para administrar el servicio.

Finalidades

  • Recibir y responder solicitudes de atención automotriz.
  • Organizar citas y órdenes de trabajo.
  • Gestionar diagnóstico, autorización, comunicación, entrega e historial del servicio.
  • Medir indicadores operativos; los resultados del proyecto académico deben presentarse sin identificar a los clientes.

Medios tecnológicos

El sitio se publica mediante GitHub Pages. Al habilitar el modo central, los datos de solicitudes y del taller se almacenan mediante Supabase. La comunicación con el cliente se realiza por WhatsApp, conforme a las condiciones del proveedor. No se publican órdenes, costos, teléfonos ni historiales.

Opciones y derechos

Para solicitar acceso, rectificación, cancelación u oposición sobre la información, contacta al taller mediante el número de WhatsApp indicado. El negocio revisará cada solicitud conforme a la normativa aplicable y a sus obligaciones de conservación.

Seguridad y límites de este prototipo

La administración requiere una cuenta autorizada cuando se habilita Supabase. El entorno DEMO usa datos sintéticos y almacenamiento exclusivo del navegador: no debe utilizarse para almacenar clientes reales. Antes del uso productivo se requieren controles de seguridad, revisión de este aviso y validación del tratamiento de datos.
